# 无人县：最后的勘界 · v0.26.0

[进入游戏](https://fionviber.github.io/dustlight-game/) · [美术图册](https://fionviber.github.io/dustlight-game/review-art.html)

这是同一份可在线部署、也可本地打开的静态游戏。下载完整仓库并解压后，双击根目录的 **index.html**；请保留同目录全部资源，无需启动本地服务器。在线、离线和不同浏览器各自保存进度，可在存档界面导出、导入 JSON 存档。

- **开始游戏**：从1885年9月1日开始，少量随身物品，随教程逐步开放地点和系统。
- **完美存档**：进入现有内容全解锁的审阅档。
- **时间 → 审阅工具 → 天气与指引**：查看雨、雪、沙尘暴和风力，演练新手指引。
- **随行簿 → 影院／留声机**：观看影片和收听历史录音；这是独立观赏馆，作品年份另有标注。
- **随行簿 → 小游戏**：贪吃蛇、2048、标准9×9初级数独；支持键盘与屏幕控件，进度跟随当前存档。小游戏期间世界暂停，切换窗口会暂停贪吃蛇。数独支持笔记、撤销和提示。
- **review-art.html**：查看现有美术资源。

本版新增小游戏目录、三套规则和5张美术素材，保留内部纹理持续演变的沙尘、地图旅行时间／体力／饱腹消耗预览，以及按场景与面板获取、解码资源的静态加载。两部影片保持原文件质量，采用无损分片；图片、字体和声音未为托管重新压缩。所有运行资源来自本仓库的静态文件，资料来源链接只用于溯源。

现有八处地点、四处室内，共12景；背景为秋季白天，两主角为8张春季完整静态立绘。完整四季与昼夜背景、多年剧情与结局、实际对白配音和 Steam 版本尚未完成。天气审阅会改变动态效果，不代表其他季节背景已经齐全。

快捷键：M 地图、B 背包、J 任务、C 日历、H 手册、Esc 返回／暂停；受当前解锁状态限制。存档包含1个自动槽和3个手动槽。

来源与许可见 [影音资料](art-sources/v21/media/README.md)、[声音来源](AUDIO_SOURCES.json)、[书籍](BOOK_SOURCES.md)、[第三方声明](THIRD_PARTY_NOTICES.md) 和 fonts 目录中的字体许可证。
