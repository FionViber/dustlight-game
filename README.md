# 无人县：最后的勘界 · v0.25.0

本地运行：解压发行包，双击 **index.html**。本项目目录中的发行入口为 **dist/index.html**，也可用“开始游戏.cmd”打开。无需Node.js、安装依赖或启动本地服务。请保留同目录资源文件，不要只复制index.html。

在线与离线使用同一套静态文件。部署到GitHub Pages、Cloudflare Pages或其他静态主机时，上传发行包的index.html及同目录文件；也支持放在网站子目录。在线、离线和不同浏览器各自保存进度，可导出/导入JSON存档转移。

- **开始游戏**：从1885年9月1日重新开始，带少量随身物品，按实际操作逐步开放随行簿、背包、手持物和地图；查看仪器箱、认识露丝、进入杂货铺可继续开放演示地点和系统。
- **完美存档**：进入已有内容全解锁基准，方便审阅。不会提前完成尚未创作的多年故事。
- **继续游戏／读取存档**：恢复真实保存进度。刷新不重置审阅档，也不自动进入完美档。
- 完美档中，**时间→审阅工具→天气与指引**可切换雨、雪、沙尘暴及风力和演练教学；演练完成或点击“结束演练”会恢复进入前的状态。
- **随行簿→影院／留声机**：两部影片与三首录音，目录标真实年份。这是用户确认的独立观赏馆，不属于1885年的故事设施。

影院提供1903《火车大劫案》（10分30秒，54.9MB）和1902《杰克与豆茎》（8分46秒，46.3MB）；不显示浏览器控件，可随时离开。发行影片与项目原片逐字节相同，仅采用无损分片方便静态加载，没有重新压缩。三首1900/1903/1909录音均小于5MB，使用自制播放、暂停、下一首。播放媒体时让出背景音乐，离开后恢复。所有运行资源由游戏所在静态网站或本地目录读取，不从资料来源网站下载。来源见 [影音资料](art-sources/v21/media/README.md)。

两级地图均为5760×3240原生画面，圆标周围略留余量的规则圆形范围可点击；仅圆标由半透明柔和变为不透明并轻亮，名称悬停出现。周边地图以近俯视表现四城间的宽阔地形与小型聚落，矿区位于康斯托克南段。地图可拖动和滚轮缩放；旅行墨铜细线从人物圆心连接目标圆标正上缘，人物圆心停在圆标正上缘，头像在其上方半重叠；缩放后保持相对位置，人物沿直线恒速移动，距离同时决定游戏耗时和体力。其他三城本轮只有地理标示。

现有八处地点、四处必要室内共12景，均为5760×2160横景。**本轮仍是秋季白天背景，两主角8张春季完整静态图；其他季节、黄昏、夜晚背景未补制。** 风线会伸展、卷曲、收尾消散并改变出生位置。季节审阅现在能切换叶片/雪花等环境效果，不代表背景图套已齐。减少动态设置会关闭天气动画，室内不出现室外降水。

对话与阅读期间实停，关闭后分别结算15分钟与10分钟；教学不扣时间。陌生人显示问号，介绍后揭名。

原有交谈、线索剪贴簿、日记、任务、服装、烹饪、劳作、德州六骰、睡眠/医疗、推理、手持物保留。快捷键M地图、B背包、J任务、C日历、H手册、Esc返回/暂停，受当前系统解锁限制。新手教学暂停世界时间，必须实际点目标、选择物品并拿在手中才推进；途中读档会回到对应步骤。当前只是开场教学和条件开放的demo，并非全部剧情与全部系统教程。

存档为当前浏览器当前地址的本地存储，有1自动槽和3手动槽。可从存档界面导出JSON备份、导入恢复；不会改写项目里的预置JSON。普通教学可自动保存；审阅演练不写入存档，临时返回快照在页面刷新后不保留。离开前可先手动保存或导出。旧版本、旧存档数据与原素材保留，本阶段不承诺新旧存档兼容。

人物与素材图册入口为发行包中的 **review-art.html**，按选择加载清晰原图。历史v0.15启动方式保持原样，上级目录“打开v0.15原版.cmd”仍对应封存版本。

美术原稿和历史来源保存在项目art-sources；用户参考目录只读。完整多年剧情、多结局、季节背景、实际对白录音、Steam接入与长期性能测试仍属后续工作。验收状态以项目PROJECT_STATUS.md及art-sources/review-v25-integration.md为准。

地图视野仅手动控制，两层地图分别记住本次运行中选择的视野；角色移动、到达不自动跟随或居中。

V0.25：沙尘内部的密度、纹理与卷涡连续演变；地图悬停显示时间、体力及饱腹消耗。资源按场景和面板读取，包含获取与解码后再显示；影片仅在选择播放时读取分块，离开后释放。天气审阅入口：完美存档 → 时间 → 审阅工具 → 天气与指引。
